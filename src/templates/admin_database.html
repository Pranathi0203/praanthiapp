Operations

Azure PostgreSQL platform actions

{% if postgres_platform_configured %}

These controls now call Linux PowerShell scripts, which use Azure CLI against your PostgreSQL Flexible Server. Point-in-time restore creates a new server from Azure backups, while server actions manage the live Flexible Server instance itself.

Database delete is executed through the Azure platform CLI. Schema repair remains available for app table recovery when you need it.
